This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

This is a small project I created to help me keep track of resources I've found when playing No Man's Sky.

Displays a list of planets and systems found with some useful information at a glance.

Can filter planets by what resources they have and systems by ruling faction and economy.

If you wanted to use this you just need to create the appropriate databases/collections in a MongoDB cluster and it should be good to go. I opt to just use the development mode because it's quick and easy to start and I don't have to deal with any hosting, and if I get an idea or if something goes wrong I can make a quick change and it's implemented immediately.
